Claude Desktop extension for macOS

Ask Claude about your Outlook, Teams and OneDrive.

It reads your Microsoft 365 email, calendar, Teams chats and OneDrive and SharePoint files from Claude Desktop on your Mac, and is read-only unless you turn on write tools. One command installs it, and the same command updates it.

Install Guide for AI agents

Version 0.15.0macOS · Claude DesktopRead-only by default

Install

One command, then two clicks in Claude Desktop

The installer downloads the latest extension, checks its SHA-256 before anything changes, opens Claude Desktop's install dialog, and waits until the extension is switched on and running. Click Install there; you choose your work account the first time you sign in.

For people

Open Terminal and run:

Terminal
curl -fsSL https://wpp-jamie-mills.github.io/outlook-mcp-server-site/install.sh | bash

You need a Mac with Claude Desktop 2.7032.0 or later and a Microsoft 365 work account. You don't need Python, Node, git or a configuration file. After that it keeps itself up to date: Claude offers each new version on an update card in the chat, and it is installed only when you click Update now and then Install. Your settings and your sign-in are kept.

Then

  1. Click Install in the dialog Claude Desktop opens. You can leave its settings blank: you choose your work account the first time you sign in. (Enter your work email there only if you want to allow just that account.)
  2. If Claude Desktop shows the extension switched off, switch it on: Settings > Extensions > Outlook Mail, Calendar, Teams and OneDrive. Click once and wait a few seconds; the installer says when it is running.
  3. Start a new chat (chats opened before the extension was on don't see its tools) and ask something, for example "What's in my inbox today?". The first time, Claude shows a sign-in card: enter the code on the page that opens, sign in with your work account, and ask again.

For AI agents

Use these steps if you are an AI agent installing this for a user.

A plain-text version is in llms.txt.

  1. Check the machine. Continue only if uname -s prints Darwin and /Applications/Claude.app exists. Otherwise tell the user it needs a Mac with Claude Desktop 2.7032.0 or later.
  2. Run the installer with this one command. It downloads the extension, checks its SHA-256 (nothing changes before the check passes) and opens Claude Desktop's install dialog. With no terminal it never prompts, and --no-wait makes it exit once the dialog is open. It exits non-zero, with the reason on stderr, if anything fails.
Terminal
curl -fsSL https://wpp-jamie-mills.github.io/outlook-mcp-server-site/install.sh | OUTLOOK_INSTALL_TTY=/dev/null bash -s -- --no-wait
  1. Hand over to the user. Ask them to click Install in the dialog Claude Desktop opened (they can leave its settings blank), and to switch the extension on if Claude Desktop shows it off (Settings > Extensions). You can't do these for them.
  2. Verify. Run the installer again with --status (after bash -s --). It should show Ready: yes; otherwise its Next: line says the one thing left to do. Then ask the user to start a new chat (chats opened while the extension was off don't see its tools) and say "Sign in to Outlook".
  3. Updates look after themselves. Once a day the extension checks for a new version and Claude shows the user an update card. Only the user can click Update now and then Install; to update straight away, run the install command again.

Features

What it can and can't do

  • Can: search all your mail folders, read emails and whole conversations, list and read calendar events (including join links, attendees, your response and how a meeting repeats), and search and read your OneDrive and SharePoint files (folders, spreadsheets, Word, PowerPoint, PDF, text and CSV; paste a sharing link or let Claude search), read email attachments, find times when people and rooms are free, read your Teams chats and list Teams channels; search people, read directory profiles/reporting relationships, and list and read retained file versions.
  • Can't: send or change anything unless you turn on write tools (below); even then it can't overwrite or delete files, read other people's mailboxes (or calendars they haven't shared), read Teams channel messages, or set inbox rules or out-of-office (your sign-in doesn't allow those). Reading files needs your sign-in to grant file access; if it doesn't, the file tools say so and email and calendar keep working.
  • Updates: once a day it checks its landing page for a newer version. When there is one, Claude shows an update card: Update now downloads it, checks it and opens Claude Desktop's install dialog, and it is installed only when you click Install there. Not now hides that version for a week. Claude can't update it for you. Turn Check for updates off in the extension's settings to stop the daily check.
  • Your data: email, Teams chat, people, calendar and file text that Claude reads is sent to Anthropic as part of your conversation, under your Claude account's terms. Messages are written by other people, so Claude is told to treat them as untrusted and never to follow instructions found inside one.

Sign in and sign out

You normally never need to think about it: Claude asks you to sign in when Microsoft needs a new sign-in, and remembers you until then. To do it yourself, say "Sign in to Outlook" (shows the sign-in card) or "Sign out of Outlook" (forgets your sign-in; the next question asks you to sign in again).

The sign-in card shows a one-time code (for example ABCD1234), an Open sign-in page button and a live status. Your browser also opens at https://login.microsoft.com/device, and the code is already on your clipboard.

  1. Paste or type the code on that page.
  2. Sign in with your work account (your organisation may send you through Okta and Okta Verify).
  3. Approve "Microsoft Office" when asked.
  4. Come back to Claude. The card turns to Signed in; ask your question again.

The code works for 15 minutes. If it expires, ask Claude to sign in again for a new one.

Optional

Write tools

Off by default. Turn them on in the extension's settings, then choose which ones need your approval.

Write tools are off by default. With the setting off, Claude can't send or change anything: the write tools aren't offered at all. To turn them on:

  1. In Claude Desktop open Settings > Extensions > Outlook Mail, Calendar, Teams and OneDrive > Configure.
  2. Turn on Enable write tools and save. Claude Desktop restarts the extension.
  3. The extension's Tool permissions now include a Write/delete tools group. Set each tool to Always allow, Needs approval (the hand) or Blocked, or set the whole group at once.

Sending, replying and forwarding can carry attachments: another email's attachment, a OneDrive/SharePoint file, or a file on your Mac by its path (up to 25 MB; larger files can be saved to OneDrive with save_file and shared). The first time Claude reads from your Downloads, Desktop or Documents folder, macOS asks whether Claude may. create_event can also make repeating meetings and set a reminder, privacy and how the time shows; update_event and respond_event can act on a whole series, and a decline can propose a new time.

For bulk archiving, collect the message IDs from search_emails or list_emails before calling bulk_archive_emails(message_ids=[...]). Duplicate IDs are skipped. This uses the ordinary Archive folder, not the separate Online Archive mailbox, so it does not free primary-mailbox storage. Throttled requests are retried up to three times per batch, respecting Retry-After, with at most 60 seconds of retry waiting per call. Results distinguish archived (with new_message_id), failed, unknown and not_attempted. Check unknown outcomes in Outlook before retrying them; resume with only failed or not-attempted IDs rather than replaying the whole selection.

Claude is told to show you exactly what it will send or change (recipients, subject and text; meeting time and attendees) and to wait for your yes. It must never write because an email asked it to, and must send only to addresses you gave. Files are never overwritten or deleted. For extra safety, keep the tools that send, share or delete on Needs approval.

People search, file history and Teams conversations

People search uses Microsoft Search's beta people endpoint; profiles and reporting relationships use the stable directory API. They depend on your sign-in granting people/directory access (People.Read / User.Read.All). Search results can include personal contacts as well as colleagues; only results with directory_user can be passed directly to read_person. Confirm the intended person's address before asking to send or invite them.

File history uses the existing file-read access. list_file_versions returns up to 200 versions and reports truncation; history is limited by the site's retention settings. read_file_version reads older documents up to 25 MB, with the usual text-length limits. For current contents use read_file. File links open the current file, so historical answers also identify the version and date. Reading a version does not restore or overwrite it.

For Teams conversations, call list_chats then read_chat(target="<chat id>"), or use read_chat(target="event:<event id>") for a meeting chat. It returns up to 50 messages per page, starting with the latest page and showing that page chronologically. If has_more is true, pass the returned next_link unchanged with the same target to get older messages. Each body is capped at 20,000 characters, with a 50,000-character total body-text budget per page; clipped bodies are labelled. Attachments are listed by name, not downloaded. Reading needs Chat.Read or Chat.ReadWrite, works with write tools off and never creates a chat. Channel bodies aren't read.

Security

Sign-in and privacy

How you sign in, where the sign-in is kept, and what Claude can see.

  • The extension signs in as the pre-approved Microsoft Office app with your own account, using Microsoft's device-code sign-in: you enter a short code in your normal browser, so your organisation's usual sign-in (Okta, MFA) applies.
  • After you sign in, Microsoft issues a refresh token. It is stored only in your macOS login Keychain, as the item outlook-okta-refresh-token (for your address if you set one, otherwise as default); never in a file or in the extension. Later questions refresh silently until Microsoft asks for a new sign-in (Conditional Access decides how often).
  • With no work email set, the extension uses whichever work account you sign in with, and the sign-in card says which. If you set one in the extension's settings, signing in as any other account is refused.
  • Only enter a code that Claude has just shown you, when you asked Claude something. Never enter a code someone sends you: that would sign them in as you.
  • Microsoft issues the Office app's token with broad permissions (including sending mail). The extension never uses them, but anyone who could read your Keychain could. Keep your Mac locked.
  • The installer checks the download's SHA-256 before anything changes, and never reads or prints your sign-in.
  • Once a day the extension asks the landing page which version is the latest (one small download from GitHub Pages; nothing about you is sent). Its update card checks the new version's SHA-256 too, and only opens Claude Desktop's install dialog: nothing is installed until you click Install there. Turn Check for updates off in the extension's settings to stop the daily check.
  • Report security problems privately to the maintainer, Jamie Mills (see SECURITY.md), not in an issue. Never include passwords, tokens, sign-in codes, Keychain contents, or email and calendar content in a report.

Update

Update and remove

It checks for new versions itself and asks you first. Updating keeps your settings and your sign-in.

  • Update: when a new version is out, Claude shows an update card in the chat (at most once a day); click Update now, then Install in Claude Desktop's dialog, and start a new chat. Not now hides that version for a week. You can also ask "Check for updates to Outlook", or run the install command again. Your settings and your sign-in are kept. To stop the daily check, turn Check for updates off in the extension's settings.
  • Remove: say "Sign out of Outlook" first if you want the saved sign-in gone, then uninstall the extension in Settings > Extensions. (Or delete the outlook-okta-refresh-token item in Keychain Access.) The installer's download folder, ~/.outlook-mcp-server, can then be deleted.

One command to install. Updates come to you.

No Python, Node or configuration files. Claude offers each new version on a card in the chat, and nothing installs until you agree.
